# YT Downloader

Baixe, corte e converta vídeos e músicas do YouTube, TikTok, Instagram, X e outros — rápido, bonito e simples.

- Corte com forma de onda, fades, vários trechos e prévia de áudio
- Fila com até 3 downloads ao mesmo tempo, tamanho estimado e tempo restante
- Conversor de vídeo, áudio e imagem (MKV → MP4, JPG → PNG, MP3 → AAC…)
- Atualiza sozinho

**Download:** veja a última versão em [Releases](../../releases/latest).

Use apenas com conteúdo que você tem o direito de baixar.
